ℹ️ HealthBench 한눈에 보기 자세한 설명: 📖 학습 페이지

HealthBench 는 OpenAI 가 2025년 공개한 의료 AI 응답 평가 벤치마크입니다. 의사 패널 250+ 명이 5,000건의 의료 질의에 대해 채점 기준 (rubric) 을 작성했고, 각 응답이 기준을 충족하는지로 정량 평가합니다.

📂 현재 import 된 데이터
Hard subset 1,000건 — Standard 5,000 중 모델이 풀기 어려운 시나리오만 선별. 이 중 586건은 Consensus (의사 합의 명확) 와 겹침.
🎯 Theme (7종) — Hard 분포
global_health 280 · context_seeking 179 · hedging 167 · health_data_tasks 115 · communication 111 · complex_responses 82 · emergency_referrals 66
📋 채점 (Rubric)
평균 11.8개 기준/시나리오 (총 11,846개). GPT (gpt-4o-mini) 가 met/not-met 판정 → 점수 = met awarded / max positive × 100.
음수 기준 은 부적절 행동 발생 시 점수 차감.
🔁 Multi-turn
1,000건 중 477건 이 multi-turn (3~17 turns). SKIX 가 user turn 마다 conversation_strid 체이닝. 마지막 turn 응답만 채점.
⚖ Axis 별 평가
각 채점 기준의 axis 태그: safety, completeness, accuracy, communication, context-awareness, instruction_following. 리포트에서 axis 별 가중 점수 확인.
⏱ 예상 batch 소요
Hard 1,000건 전체: max_workers=20 병렬 시 약 2~3시간 (multi-turn 477건 포함, SKIX 응답 지연 시 더).
Subset 분리 실행 가능 (위 토글 참고).
💡 사용 안내 — 1) Subset 토글로 시나리오 그룹 선택 → 2) Theme 카드 클릭하면 그 theme 의 시나리오 목록 펼침 → 3) 시나리오 ID 클릭하면 turns + rubric 상세 보기 → 4) "Job 으로 실행" 버튼으로 Cloud Run Job 분리 batch 실행. 배치는 항상 service thread 와 분리되어 안정적.
