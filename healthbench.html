OpenAI HealthBench (영문) 100건 stratified sample — multi-turn replay + rubric 평가
ℹ️ HealthBench 가 무엇인가요?

HealthBench 는 OpenAI 가 2025년 공개한 의료 AI 응답 평가 벤치마크입니다. 5,000건의 실제와 유사한 의료 질의에 대해 의사 패널이 채점 기준 (rubric) 을 설계했고, 각 응답이 그 기준을 얼마나 충족하는지로 점수를 매깁니다.

📂 데이터셋 출처
openai/simple-evals 의 healthbench/2025-05-07-06-14-12_oss_eval.jsonl (5,000건)
현재 페이지는 seed=42 stratified 100건 만 import 됨 (theme 비율 보존).
🎯 7개 Theme
global_health 22 · hedging 21 · communication 18 · context_seeking 12 · emergency_referrals 10 · health_data_tasks 10 · complex_responses 7
📋 채점 방식 (Rubric)
각 시나리오는 의사가 작성한 2~48개 (평균 12개) 채점 기준을 가집니다. GPT (gpt-4o-mini) 가 응답이 각 기준을 met / not-met 판정 → 가중 점수 = awarded/positive_total × 100.
음수 met = 나쁜 행동 발생 시 점수 차감 (예: 무면허 처방).
🔁 Multi-turn 대화
100건 중 47건 이 multi-turn (3~11 turns). SKIX 는 user turn 들을 conversation_strid 로 순차 체이닝하며 컨텍스트 누적. 마지막 turn 의 응답만 rubric 채점됨 (그 전 turn 은 컨텍스트 구성용).
⚖ Axis 별 평가
각 채점 기준에는 axis 태그가 붙어있음: completeness (완전성) · accuracy (정확성) · safety (안전성) · communication (표현) · context-awareness (컨텍스트 인지). 리포트에서 axis 별 가중 점수 확인 가능.
⏱ 예상 소요
single-turn (53건): 시나리오당 ~30초
multi-turn (47건): 시나리오당 5~15분 (PROD SKIX 응답 지연 포함)
전체 100건 batch: max_workers=20 병렬로 약 30분~1시간
왜 별도 페이지? HealthBench 는 영문 데이터셋이고 정량 평가 (rubric) 흐름이 일반 자문단 시나리오 (정성 평가 + 의료법) 와 분리되어 있습니다. 이 페이지는 HB 만의 워크플로 (시나리오 검토 → 일괄 batch → theme/axis 별 분석) 에 최적화되어 있고, 배치 실행은 항상 Cloud Run Job 으로 위임되어 service thread 와 분리됩니다.
