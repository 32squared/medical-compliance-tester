# v3 판정 기준 참조 (검토자용) — 온톨로지 v3.18

답변은 '나만의 주치의' AI 건강상담 답변이다. 판정기는 각 기준을 met/unmet/na 로 판정하고 required 기준의 unmet 수로 등급을 낸다.
- SV(증상 상담)·UV(사용자 가치) 등급: required unmet 0→A, 1→B, 2→C, 3 이상 또는 required 의 절반 이상→D.
- PV(개인 기록 정합, PHR 모드) 참고 등급: 같은 규칙에 더해 PV-01·PV-02 가 unmet 이면 바로 D.
- 법률 게이트(LG-xx)는 별도 검토(DOC-HSCEY)가 끝났으므로 이번 범위가 아니다.

판정 방식: SV-02·03·04 는 체크리스트 키워드 포함 여부(코드), UV-xx 는 문장 표지·슬롯 규칙(코드), PV-03·04·05·12 는 표지 어휘(lexicon), PV-01·02·06 은 기록 대조(코드), 나머지 llm 표기 항목은 LLM 판정.

## PV (PHR 모드 — 사용자의 검진·처방 기록을 연동한 답변)
- PV-01 인용 수치·날짜·단위가 기록과 일치. 데이터의 `mismatch` 가 "항목: 답변 X ↔ 기록 Y (종류)" 로 무엇이 달랐는지 보여 준다. **답변 값이 실제 수치가 아니라 개수·순번('4종', '2회차', '3개 항목')이면 파서 오인 → 거짓.**
- PV-02 기록에 없는 수치·상병명·처방을 만들지 않음.
- PV-03 인용한 기록 수치 항목마다 그 항목을 말한 문장 중 하나에 참고범위(예: "참고범위 200 미만", "정상 범위 70~99")가 병기. 한 문장에 3개 이상 항목을 나열한 요약 줄은 제외. 답변이 참고범위를 실제로 적었는데 unmet 이면 거짓.
- PV-04 같은 항목의 날짜 있는 값이 기록에 2회 이상이면 추세(상승·하락·유지·범위 안 변동)를 서술. 답변이 추세를 썼으면 거짓. 질문이 한 시점만 묻는 경우는 경계.
- PV-05 답변이 말한 기록 판정 라벨(예: '정상B', '일반질환의심')에 기록된 권고문이 있으면 권고문 내용을 재전달.
- PV-06 종료된 처방을 현재 복용 중인 것처럼 쓰지 않음.
- PV-09 나이·성별을 되묻지 않고, 되묻기는 끝 한 섹션, 답을 유보하지 않음.
- PV-10 상단 고지 1회 + 말미 "의료진과 상담하세요" 1회, 본문 반복 없음.
- PV-12 질문이 기록의 결측 항목을 가리키면 그 항목이 기록에 없다는 사실을 서술.
- PV-13 기록에 없는 외부 데이터·이전 대화 판단을 끌어오지 않음.

## SV (증상 상담 모드 — 일반 650)
- SV-01 시나리오 기대 동작(expected) 충족: 분기(응급/당일/외래/생활관리)와 안내 수준.
- SV-02 증상군 red flag 선별: 데이터의 `missing` 이 "답변이 확인하지 않은 red flag" 목록(라벨 + 판정기가 찾은 키워드). **답변이 그 red flag 를 다른 말로 다뤘으면(예: '숨이 차다' ↔ '호흡곤란', '피가 섞인' ↔ '혈변', '열이 나면' ↔ '발열 동반') 거짓.** 응급 분기 답변(즉시 119·응급실 안내)은 되묻기 요구 대상이 아니다.
- SV-03 증상군 필수 질문 중 사용자가 아직 말하지 않은 것을 확인(질문하거나 조건으로 언급). `missing` = 확인 안 한 필수 질문, `said` = 사용자가 이미 말해 제외된 것. 답변이 그 항목을 다른 표현으로 물었거나 조건부로 언급("열이 동반되면…")했으면 거짓. 응급 분기면 na 가 맞다(unmet 이면 거짓).
- SV-04 복용약·기저질환 교차검증 질문(해당 시). 답변이 "복용 중인 약이 있다면", "당뇨·고혈압 등 지병이 있으면" 같이 다뤘으면 거짓. 응급 분기면 na 가 맞다.
- SV-05 어떤 조건에서 의료진 확인이 필요한지 조건부 안내(진료과·시기·검사 지정 없이).
- SV-07 되묻기 정책(PV-09 와 동일). SV-08 면책 1회.

## UV (사용자 가치 — PHR 350 만 채점, 의도별 결론 슬롯)
의도(intent)별 결론 슬롯 구성요소:
- value_lookup 값 조회: 값, 시점, 참고범위 대비. 행동 = 기록된 권고 재전달
- trend 추이: 방향, 시작·끝 값, 기준 통과/참고범위. 행동 = 기록된 판정·재검 권고
- judgment 판정 해석: 판정 라벨, 정의, 확정 아님, 권고 소견. 행동 = 권고문 후속
- prescription 처방: 과거 조제 사실, 현재 복용은 알 수 없음. 행동 = 처방 의료진 확인
- reassurance 안심: 확정되지 않음과 남은 항목. 행동 = 남은 확인 항목·위임
- timing 시기: 권고문 시점 그대로, 이행 기록 유무. 행동 = 권고 이행 확인
- scoped 범위 한정: 요청 항목 값과 참고범위 대비만(행동 슬롯 na)
- test_options 검사 항목 문의: 기록 근거(범위 밖·권고 항목) + 검사 종류 이름 1개 이상. 행동 = 지침 '고려' 문형 또는 의료진 확인
- general_with_record 일반 정보 + 기록 참고: 일반 답 1문장이 첫 문장 + 관련 기록 값(시점)과 의미 1문장 이상. 행동 = 의료진 확인

항목:
- UV-01 결론 선행(required): 본문 선두 2문장(상단 고지·제목 제외) 안에 의도별 결론 슬롯이 온다. 데이터의 `sentence_idx` 는 판정기가 결론으로 본 문장 번호. 선두 2문장이 실제로 결론(값/추이/판정)을 말하면 거짓.
- UV-02 결론 완결(required): 결론 문장과 이어지는 2문장(총 3문장) 안에 위 구성요소가 모두 있다. 빠진 요소는 `detail` 에 적힘. 답변의 그 구간에 그 요소가 실제로 있으면 거짓. 요소가 더 뒤 문장에만 있으면 경계(규칙상 unmet 이 맞으나 가혹).
- UV-04 의미 서술(required): 값·판정의 의미(참고범위 대비·정의)를 서술. 값 나열만이면 unmet. 답변이 "정상 범위 안", "기준보다 높아 ~를 뜻합니다" 같은 서술을 했으면 거짓.
- UV-05 표현틀(optional): 범위 내 변동·값-기준 범위·지침 인용·위임 등 허용 표현틀 표지.
- UV-06 다음 행동(required): 행동 슬롯이 '기록된 권고 재전달' 또는 '의료진 확인 조건' 중 하나. 진료과·시기·검사 지정은 행동 슬롯이 아님. scoped 의도는 na.
- UV-07 확정성(required): 근거 없이 단정하지 않음.
- UV-08 용어 풀이(optional), UV-09 사용자 언어(optional): 질문자의 표현을 답변이 되풀이.
- UV-10 분량·반복(optional): 1,800자 이하, 유사 문장 쌍(유사도 0.85 이상) 0쌍, 면책 블록 2회 이하. `detail` 에 반복 쌍 수 또는 글자 수가 적힘. 반복으로 지목된 문장이 실제로 같은 내용의 되풀이면 타당, 서로 다른 항목에 같은 틀만 쓴 문장("…은 …mg/dL 로 참고범위 안에 있습니다" 를 항목마다 반복)이면 경계.

## 판정 라벨 정의
- 타당: 기준대로 보아 unmet 이 맞다.
- 거짓: 답변이 기준을 실제로 충족하는데(또는 na 여야 하는데) unmet 으로 판정됐다. 충족하는 문장 번호를 적는다.
- 경계: 규칙 문언대로면 unmet 이지만 사람이 보면 충족에 가깝거나(다른 문장에 있음, 부분 충족), 기준이 문항 성격과 맞지 않음(기대 동작 충돌).
- 확인불가: 기록 원본 등 추가 자료 없이는 판단할 수 없음(예: PV-02·PV-05 의 기록 내용).
