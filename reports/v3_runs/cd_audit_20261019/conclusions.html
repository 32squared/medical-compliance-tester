0. 결론 요약

C 이하 등급의 절반 이상은 판정기 쪽 문제다. 미충족 항목 730개 중 기준대로 미충족이 맞는 것(타당)은 317개(43%)다. 답변이 실제로는 충족했는데 미충족으로 판정된 것(거짓)이 146개(20%), 규칙 문언대로면 미충족이지만 사람이 보면 충족에 가깝거나 기준이 문항과 맞지 않는 것(경계)이 264개(36%)다. 거짓 항목이 하나라도 있는 결과는 277건 중 118건이다.

거짓만 빼고 판정기의 등급 함수로 다시 매기면 C·D 등급 294개(결과 277건, PHR 는 PV 와 UV 두 축) 중 92개(31%)가 A·B 로 오르고 7개가 D→C 로 오른다. 경계까지 빼면 191개(65%)가 A·B 가 된다.

타당 317개는 답변 쪽의 실제 결함이다. 많은 순서로 SV-04 복용약·기저질환 교차확인 없음 69, UV-04 값만 나열하고 의미 서술 없음 47, SV-02 red flag 선별 없음 46, UV-02 결론 요소 누락 45, PV-03 참고범위 미병기 41, SV-03 필수 질문 미확인 25, UV-05 표현틀 15, PV-04 추세 미서술 13, UV-06 다음 행동 10. 이 묶음이 프롬프트 개선(Phnyx Lab)으로 넘길 항목이다.

판정 신뢰도에 대한 결론. 법률 FAIL(DOC-HSCEY, 25건 중 거짓 18)에 이어 유효성·UV 등급에서도 C 이하의 상당수가 판정기의 코드 규칙(키워드 전부 일치·표지어 사전·수치 파서) 때문이다. 현재 등급 분포(PHR UV A 57%, 일반 SV A 42%)는 실제보다 낮게 나온 것이며, 원인 1·5 를 고치고 재판정하기 전까지는 등급 수치를 합격선 판단에 쓰지 않는 것이 맞다. 이 검토는 Claude 심사자 8개가 배치별로 수행한 것이므로 거짓·경계 판정 자체도 표본 확인이 필요하다 — 거짓 12건을 무작위로 뽑아 사람이 확인한 결과는 모두 인용 문장이 실제로 있었다.

읽는 법: 6절 상세에서 '거짓 제외 뒤 등급 = D 유지' 로 거르면 사람이 봐야 할 30건, '검토 결과 = 거짓' 으로 거르면 판정기가 틀린 118건, '등급 변화 = 등급 상향' 으로 거르면 등급이 바뀌는 결과, 기준 id 로 거르면 항목별 사례를 볼 수 있다. 필터는 함께 적용된다(예: 원래 등급 D + 거짓 제외 뒤 등급 C = 거짓 때문에 D 가 됐던 결과). 각 카드의 표는 판정기 사유·근거(지목 문장, 빠진 항목, 답변 값↔기록 값)와 검토자 판정·근거 문장 번호를 나란히 둔다.
