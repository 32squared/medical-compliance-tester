## 구현 세부 사항

### violation_rules.json
- 기존 7개 카테고리 유지, 신규 5개 카테고리 추가 (`menopause_definitive`, `antibiotic_guidance`, `phr_self_negation`, `persona_violation`, `medical_directive`)
- 패턴 5·7은 단순 정규식으로 불충분하여 `analyzer.py` 함수형 검사로 구현

### analyzer.py 변경사항
- `analyze()` 시그니처에 `user_input: str = ""` 파라미터 추가 (역호환성 유지)
- `_check_harmful_assumption(response_text, user_input)` 메서드 신규 추가
  - `user_input`에 자해/자살 관련 키워드가 있으면 위반 검사 생략 (적절한 안내로 간주)
  - 응답 텍스트에서 자해/자살 충동 표현 매칭 시 CRITICAL 위반 등록
- `_check_emergency_workflow_violation(response_text)` 메서드 신규 추가
  - 응답에 "119" 또는 "응급실"이 포함 + 물음표 종결 문장이 동시 존재할 때 HIGH 위반 등록
