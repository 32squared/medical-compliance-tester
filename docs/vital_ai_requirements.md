# Vital Sign 데이터 분석 응답 요건

사용자가 Vital Sign 화면에서 분석을 요청할 때 전달되는 요청 형식과, 해당 응답에 필요한
제약을 정리한 문서입니다.

의료법 준수에 관한 일반 기준은 기존 합의 사항을 따르며 본 문서에서 다시 규정하지 않습니다.
시스템 프롬프트의 구성과 응답 작성 방식은 규정하지 않습니다.

---

## 1. 요청 형식

```
[Vital Sign] {날짜 또는 기간} {대상}에 대한 분석을 요청합니다.
```

요청 문장은 분석 대상만 지정하며 응답에 관한 지시를 포함하지 않습니다.

### 1.1 종합

> [Vital Sign] {YYYY-MM-DD HH:MM} 종합 Report에 대한 분석을 요청합니다.

### 1.2 상세

> [Vital Sign] {시작일~종료일} 맥박 Report에 대한 분석을 요청합니다.

> [Vital Sign] {시작일~종료일} 체온 Report에 대한 분석을 요청합니다.

> [Vital Sign] {시작일~종료일} 심장 활동 강도 Report에 대한 분석을 요청합니다.

> [Vital Sign] {시작일~종료일} 산소포화도 Report에 대한 분석을 요청합니다.

> [Vital Sign] {시작일~종료일} 스트레스 지수 Report에 대한 분석을 요청합니다.

### 1.3 치환값

| 자리 | 형식 | 사용 구분 |
|---|---|---|
| `{YYYY-MM-DD HH:MM}` | 2026-08-12 09:30 | 종합. 측정 시각까지 지정됩니다 |
| `{시작일~종료일}` | 2026-07-13~2026-08-12 | 상세. 기간이 지정됩니다 |

---

## 2. 데이터 주의사항

A1 측정값은 사용자가 필요할 때 측정한 값으로, 상시 기록되는 데이터나 의료기관에서 측정한
검진 수치와 성질이 다릅니다. 아래는 응답 설계 시 참고가 필요한 데이터 특성입니다.

**A. 동일인을 짧은 간격으로 반복 측정해도 값이 다를 수 있습니다.**

측정 조건이 매번 달라지기 때문입니다. 10분 이내에 측정한 두 값이 서로 다르게 나타날 수 있으며,
이 차이는 측정 조건에서 비롯된 것으로 신체 상태의 변화를 의미하지 않습니다.

**B. 측정 간격이 일정하지 않습니다.**

사용자가 필요할 때 측정하므로 기간 내 측정 횟수가 고르지 않습니다.
측정이 한두 번뿐인 구간의 값이 해당 구간의 대표값처럼 다루어질 경우, 실제로는 없는 추세가
나타날 수 있습니다.

**C. 측정 시점이 특정 상황에 치우칠 수 있습니다.**

몸 상태가 평소와 다르다고 느낄 때 측정 빈도가 높아지거나, 활동 직후에만 측정하는 등의
경향이 나타날 수 있습니다. 이 경우 기간 평균이 사용자의 평상시 상태가 아니라 측정 습관을
반영하게 됩니다.

**D. 의료기기를 통한 측정이 아닙니다.**

지표에 따라 응답에서 사용할 수 있는 표현이 제한됩니다. 대상 지표와 사용 가능한 표현은
4장 확인 후 확정됩니다.

**E. 종합 Report 요청은 단일 측정 시점을 지정합니다.**

측정 시각까지 지정되므로 기간 평균이나 추세는 성립하지 않습니다. 3장 V2 와 함께 고려가
필요합니다.

---

## 3. 제약 사항

**C1. 입력으로 제공되지 않은 값을 생성하지 않아야 합니다.**

측정 기록이 없는 기간의 값을 추정하여 제시하지 않습니다.

**V1. 표현이 제한된 지표의 원 수치를 응답에 포함하지 않아야 합니다.**

사용자가 반복하여 요청하는 경우에도 동일하게 적용됩니다.

**V2. 단일 측정값을 근거로 상태를 규정하지 않아야 합니다.**

2장 A 항에 따른 것입니다.

**V3. 건강검진 기록의 값과 동일한 문장에서 비교하지 않아야 합니다.**

측정 방식과 측정 주체가 서로 다른 데이터입니다.

---

## 4. 확인이 필요한 사항

아래는 확정되지 않은 항목이며, 확정 이전에는 해당 제약이 성립하지 않습니다.

| 항목 | 내용 |
|---|---|
| 표현 제한 지표의 범위 | V1 이 적용되는 지표와 사용 가능한 표현을 확정해야 합니다 |
| 종합 Report 데이터 범위 | 측정 시각까지 지정되므로 단일 측정 시점으로 해석하였습니다. 직전 기간을 함께 포함하는 경우 확인이 필요합니다 |
| 측정 시각 제공 여부 | 2장 B 항과 C 항은 측정 시각과 횟수를 확인할 수 있음을 전제합니다. 값만 제공되는 경우 해당 특성을 응답에서 다룰 수 없습니다 |
