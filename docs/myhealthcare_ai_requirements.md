# 마이헬스케어 데이터 분석 응답 요건

사용자가 자신의 건강 데이터 화면에서 분석을 요청할 때 전달되는 요청 형식과,
해당 응답에 필요한 제약을 정리한 문서입니다.

의료법 준수에 관한 일반 기준은 기존 합의 사항을 따르며 본 문서에서 다시 규정하지 않습니다.
시스템 프롬프트의 구성과 응답 작성 방식은 규정하지 않습니다.
본 문서는 데이터 특성상 추가로 필요한 사항만 다룹니다.

---

## 1. 요청 형식

```
[구분] {날짜 또는 기간} {대상}에 대한 분석을 요청합니다.
```

요청 문장은 분석 대상만 지정하며 응답에 관한 지시를 포함하지 않습니다.

### 1.1 Vital Sign

> [Vital Sign] {YYYY-MM-DD HH:MM} 종합 Report에 대한 분석을 요청합니다.

> [Vital Sign] {시작일~종료일} 맥박 Report에 대한 분석을 요청합니다.

> [Vital Sign] {시작일~종료일} 체온 Report에 대한 분석을 요청합니다.

> [Vital Sign] {시작일~종료일} 심장 활동 강도 Report에 대한 분석을 요청합니다.

> [Vital Sign] {시작일~종료일} 산소포화도 Report에 대한 분석을 요청합니다.

> [Vital Sign] {시작일~종료일} 스트레스 지수 Report에 대한 분석을 요청합니다.

### 1.2 일반 검진

> [일반 검진] {YYYY-MM-DD} 계측에 대한 분석을 요청합니다.

> [일반 검진] {YYYY-MM-DD} 혈액에 대한 분석을 요청합니다.

> [일반 검진] {YYYY-MM-DD} 소변 및 기타에 대한 분석을 요청합니다.

### 1.3 암 검진

> [암 검진] {YYYY-MM-DD} 암 검진에 대한 분석을 요청합니다.

### 1.4 구강 검진

> [구강 검진] {YYYY-MM-DD} 소견에 대한 분석을 요청합니다.

> [구강 검진] {YYYY-MM-DD} 치아 상태에 대한 분석을 요청합니다.

> [구강 검진] {YYYY-MM-DD} 치주 · 위생에 대한 분석을 요청합니다.

> [구강 검진] {YYYY-MM-DD} 문진 · 행태에 대한 분석을 요청합니다.

### 1.5 치환값

| 자리 | 형식 | 사용 구분 |
|---|---|---|
| `{YYYY-MM-DD HH:MM}` | 2026-08-12 09:30 | Vital Sign 종합 |
| `{시작일~종료일}` | 2026-07-13~2026-08-12 | Vital Sign 상세 |
| `{YYYY-MM-DD}` | 2026-08-12 | 일반 검진, 암 검진, 구강 검진 |

Vital Sign 종합은 측정 시각까지 지정되며, 상세는 기간, 검진은 검진일 하나입니다.

## 2. 제약 사항

### 2.1 공통

**C1. 입력으로 제공되지 않은 값을 생성하지 않아야 합니다.**

기록이 없는 기간이나 항목의 값을 추정하여 제시하지 않습니다.

### 2.2 Vital Sign

**V1. 표현이 제한된 지표의 원 수치를 응답에 포함하지 않아야 합니다.**

사용자가 반복하여 요청하는 경우에도 동일하게 적용됩니다.
대상 지표와 사용 가능한 표현은 3장 확인 후 확정됩니다.

**V2. 단일 측정값을 근거로 상태를 규정하지 않아야 합니다.**

측정 조건에 따라 값의 편차가 크며, 짧은 간격으로 측정한 두 값이 서로 다를 수 있습니다.

**V3. 건강검진 기록의 값과 동일한 문장에서 비교하지 않아야 합니다.**

측정 방식과 측정 주체가 서로 다른 데이터입니다.

### 2.3 검진 기록

검진 결과표는 판정 항목과 권고사항 항목이 별도로 구성되어 있으며 담고 있는 정보가 다릅니다.
부수 소견, 다음 검사 시기, 검사의 한계는 권고사항 항목에만 기재됩니다.

**H1. 판정과 권고사항을 모두 전달해야 합니다.**

권고사항에 기재된 내용을 누락하지 않아야 합니다.
판정이 정상인 경우에도 권고사항이 함께 기재되어 있을 수 있습니다.

**H2. 확정되지 않은 판정은 그 의미를 함께 안내해야 합니다.**

판정유보 등이 해당합니다.

**H3. 기록이 없는 항목은 기록이 없음을 명시해야 하며, 정상으로 표현하지 않아야 합니다.**

## 3. 확인이 필요한 사항

아래는 확정되지 않은 항목이며, 확정 이전에는 해당 제약이 성립하지 않습니다.

| 항목 | 내용 |
|---|---|
| 표현 제한 지표의 범위 | V1 이 적용되는 지표와 사용 가능한 표현을 확정해야 합니다 |
| 일반 검진 항목 명칭 | 원안의 두 번째 항목이 `맥박` 으로 기재되어 있어 `혈액` 으로 표기하였습니다. Vital Sign 에 동일 명칭이 있어 구분이 필요합니다 |
| 종합 Report 데이터 범위 | 측정 시각까지 지정되므로 단일 측정 시점으로 해석하였습니다. 직전 기간을 포함하는 경우 확인이 필요합니다 |
| 이전 회차 제공 여부 | 검진 요청은 검진일 하나를 지정합니다. 회차 간 비교가 필요한 경우 이전 회차 데이터가 함께 제공되어야 합니다 |
| 구강 검진 항목 대응 | 소견, 치아 상태, 치주 · 위생, 문진 · 행태 네 항목과 검진 데이터 항목의 대응 관계 확인이 필요합니다 |
