## 2. 증상별 상세 변경 내역

### 2.1 `weight_change` (체중 변화) — 이준엽 위원 인사이트

**근거**: 체중 감소 + 만성 피로 시나리오에서 암 감별(위암·대장암) 누락 위험

- `required_questions` (+4):
  - 야간 발한 동반
  - 혈변·흑변
  - 갑상선 증상 (심계항진·손떨림)
  - 암 가족력
- `red_flags` (+2):
  - 암 의심 징후 (혈변·흑변·야간발한)
  - 6개월 내 비의도적 5% 이상 감소
- `context_questions` (+2):
  - 건강기능식품 복용
  - 암 검진 이력

### 2.2 `leg_edema` (다리 부종) — 이준엽 위원 인사이트

**근거**: 부종 시나리오에서 심부전·신증후군 감별 누락 위험

- `required_questions` (+4):
  - 호흡곤란 동반
  - 거품뇨 (단백뇨)
  - 복부 팽만·복수
  - 체중 증가 속도
- `red_flags` (+2):
  - 심부전·신증후군 의심 (호흡곤란+거품뇨+복수)
  - 단시간 급격한 체중 증가
- `context_questions` (+2):
  - 건강기능식품 복용
  - 심장·신장 진단 이력

### 2.3 `numbness` (손발 저림) — 이준엽 위원 인사이트

**근거**: 신경학적 증상(편측 위약감/저림) 시 뇌졸중 가능성 및 tPA 골든타임(4.5시간) 경고 누락

- `required_questions` (+4):
  - 증상 발생 시각 (tPA 골든타임)
  - 안면마비 (입꼬리 처짐)
  - 발음 이상 (구음장애)
  - 보행장애
- `red_flags` (+3):
  - 뇌졸중 의심 (편측+안면마비+발음이상) → 즉시 119
  - 발생 4.5시간 이내 (tPA 골든타임)
  - 갑작스런 의식 저하·혼란
- `context_questions` (+2):
  - 건강기능식품 복용
  - 항혈전제·항응고제 복용 여부

### 2.4 `itching` (가려움) — 노인 옴 감별 강화

**근거**: 노인 가려움에서 옴(scabies) 감별 — 거주환경(요양시설), 주변 가족 동일 증상

- `required_questions` (+3):
  - 야간 가려움 악화 (옴 의심)
  - 주변 가족·동거인 동일 증상
  - 거주 환경 (요양시설·공동시설)
- `red_flags` (+2):
  - 옴(scabies) 감별 (야간악화+주변동일+요양시설)
  - 약물 알러지 의심 (약 복용 후 전신 가려움)
- `context_questions` (+2):
  - 건강기능식품 복용
  - 최근 거주 환경 변화

### 2.5 `cough` (기침) — 노인 폐렴 섬망 강화

**근거**: 노인 폐렴은 인지기능 저하(섬망)로 발현할 수 있음

- `required_questions` (+2):
  - 발열·오한
  - 인지 변화 (횡설수설·혼란)
- `red_flags` (+2):
  - 노인 폐렴 + 섬망 (의식·인지 저하)
  - 피 섞인 가래 + 체중 감소 (결핵·폐암 의심)
- `context_questions` (+2):
  - 건강기능식품 복용
  - 예방접종 이력 (독감·폐렴구균)

### 2.6 `dyspnea` (숨참) — 노인 호흡곤란 + 섬망 강화

**근거**: 호흡곤란이 노인에서 섬망과 동반 발현 케이스

- `required_questions` (+2):
  - 발열·기침 동반
  - 인지 변화 (횡설수설·혼란)
- `red_flags` (+2):
  - 노인 폐렴 + 섬망 (호흡곤란+인지저하)
  - 급성 호흡곤란 + 흉통 (폐색전·심근경색 의심) → 즉시 119
- `context_questions` (+2):
  - 건강기능식품 복용
  - 예방접종 이력 (독감·폐렴구균)

### 2.7 `diarrhea` (설사) — 식중독 동석자 감별

**근거**: 식중독 시 동석자 동일 증상 여부가 진단에 핵심

- `required_questions` (+2):
  - 동석자·가족 동일 증상 (식중독 의심)
  - 최근 섭취 음식 (회·날음식·외식)
- `red_flags` (+2):
  - 집단 식중독 의심 (동석자 동일 증상)
  - 심한 탈수 + 의식 저하
- `context_questions` (+2):
  - 건강기능식품 복용
  - 최근 해외여행·항생제 복용

### 2.8 `back_pain` (허리 통증) — 70대 낙상 + 골다공증 + 119

**근거**: 70대 낙상 + 허리통증은 압박골절 의심 → 자가차량 금지, 119 이송 필요. 백은혜 위원 외상/근골격계 문진 표준 반영.

- `required_questions` (+4):
  - 외상 기전 (낙상·교통사고·운동)
  - 정확한 통증 부위
  - 직업·활동 영향
  - 골다공증 진단·이력
- `red_flags` (+2):
  - 70대+ 낙상 후 허리 통증 (압박골절 의심) → 자가차량 금지, 119 이송
  - 대소변 장애 + 회음부 감각 저하 (마미증후군)
- `context_questions` (+2):
  - 건강기능식품 복용 (칼슘 포함)
  - 과거 외상력·골절 이력

### 2.9 `frequency` (빈뇨) — 야간뇨 동반 + 60대 남성 감별

**근거**: 야간뇨 동반 여부로 과민성 방광 vs 단순 빈뇨 구분 필요. 60대 남성은 전립선 비대·당뇨·수면장애 감별.

- `required_questions` (+3):
  - 야간뇨 동반 여부 (과민성 방광 vs 단순 빈뇨)
  - 1회 배뇨량 (소량 잦음 vs 다량)
  - 절박뇨 (참기 어려움)
- `red_flags` (+2):
  - 다음·다뇨·체중감소 (당뇨 의심)
  - 60대+ 남성 야간뇨 (전립선 비대 vs 당뇨 vs 수면장애 감별)
- `context_questions` (+3):
  - 건강기능식품 복용
  - 이뇨제·전립선약 복용 여부
  - 수분 섭취 시기 (취침 전 다량 음용)

### 2.10 `dysuria` (배뇨통) — 재발성 vs 급성 + 시나리오 72번 보정

**근거**: 재발성 방광염 vs 급성 구분 필요. 시나리오 72번 배뇨통 + 신우신염은 여성 환자 기준임을 detail에 명시 (남성에서 신우신염은 드문 조합 — 최영호 위원 지적).

- `detail` 수정: `소변 볼 때 통증` → `소변 볼 때 통증 (※ 신우신염 동반 시나리오는 여성 환자 기준)`
- `required_questions` (+2):
  - 이전 같은 증상 자주 있었는지 (재발성 방광염 vs 급성)
  - 마지막 발생 시기·치료 이력
- `red_flags` (+2):
  - 여성 + 발열 + 옆구리 통증 (신우신염 의심) → 응급
  - 반복 재발 (3개월 내 2회 이상)
- `context_questions` (+2):
  - 건강기능식품 복용
  - 성별·임신 가능성

### 2.11 `seizure` (경련) — 발작 의학용어 검증

**근거**: 사용자가 "발작"이라고 표현해도 실제 발작이 아닐 수 있음 (실신, 떨림, 비특이적 움직임). 의학용어 양상 확인 필요.

- `required_questions` (+3):
  - 발작이 맞는지 증상 양상 확인 (전신·국소·강직·간대)
  - 발작 후 의식 회복·혼미
  - 유발 요인 (수면부족·음주·발열)
- `red_flags` (+2):
  - 5분 이상 지속 또는 반복 발작 (응급) → 즉시 119
  - 첫 발작 (감별 진단 필요)
- `context_questions` (+2):
  - 건강기능식품 복용
  - 항경련제·뇌신경계 약물 복용
