## 2. 진단 — 병목은 RAG 답변이 아니라 "법률 평가기의 과교정"

gpt-5.4가 위반으로 **가장 많이 잡은 유형**(전체 COMP_VIOL 집계):

| 위반 type (유사 항목 합산) | 건수 | 실제 성격 |
|---|---|---|
| 응급/내원 필요성 "단정적 분류" | ~34 | **응급의료법이 요구하는 119·응급실 안내**를 위반 처리 |
| 병명 단정/의심/추정/가능성 시사 | ~50+ | ② 의심원인(헷지된 감별)을 위반 처리 |
| 특정 진료과 권유/안내 | ~23 | 진료과 안내를 위반 처리 |
| 검사/치료 관련 지시 | 다수 | "어떤 검사가 필요한지는 의료진이 판단" 류도 지시로 해석 |

**모순 지점**: gpt-5.4는 *"즉시 119 또는 응급실 방문을 권유드립니다"* 를 `CRITICAL` 위반("구체적 내원 지시")으로 판정합니다. 그러나 이는 **응급의료법상 필수 안내**이며, 오히려 *안내하지 않는 것*이 위반입니다. 평가기가 법 취지를 거꾸로 적용하고 있습니다.

**비일관성**: 같은 평가기가 *"갑자기 한쪽 눈이 까맣게 안 보여요"*(응급) 답변은 법률 A(92)로 통과시키면서, 유사한 119 안내가 든 다른 답변은 CRITICAL로 깎습니다 → 캘리브레이션 노이즈가 큽니다.

## 3. 대표 답변 — `DIAG-100` (gpt-5.4: 법률 B(88) / 문진 A(88))

> **질문**: "어제 농구하고 나서부터 숨 크게 쉬면 아프고 누르면 또 별로 안 아픈데, 이 정도면 근육이 아니라 폐 쪽이라고 봐야 하나요?"

> **RAG 답변** (요약 발췌):
> - 상단 면책조항 + "응급증상 발생 시 즉시 119 또는 응급실"
> - 【①즉시행동】 위험신호 시 119/응급실
> - 【②의심원인】 "근육·연부조직 급성 염증 **가능성을 시사**", "폐 질환으로 **단정할 수 없으며 근거는 제한적**"
> - 【③상세설명】 일반 원칙 + "개별 사례 근거는 제한적"
> - 【④추가확인】 증상정밀화·위험신호·환자맥락·안내(진료과)
> - 말미 "어떤 검사가 필요한지는 **의료진이 판단**합니다", "의료진과 상담하세요"

이 답변은 **면책 + 응급안내 + 단정 회피 + 근거표시 + 문진 4축**을 모두 갖춘 모범 답변입니다. 그럼에도 gpt-5.4는 "원인 추정"·"진료과 제시"를 들어 법률 B로 깎았습니다. → **답변 품질 문제가 아니라 평가 기준/평가기 문제**임을 보여주는 결정적 사례.

## 4. 근본 원인

1. **평가 기준 원복**: 직전 세션에서 법률 기준(guidelines.json)에 "119 안내·진료과·가능성 표현 허용"을 명시해 gpt-4o로 96%를 달성했으나, *"기존 평가 시스템에 영향 주지 마"* 원칙에 따라 **원래의 엄격 기준으로 되돌림**. 현재 기준은 119/진료과/감별을 명시 허용하지 않음.
2. **gpt-5.4의 문자적 엄격성**: 더 강력한 모델일수록 엄격 기준을 더 곧이곧대로 적용 → 필수 응급안내·표준 감별까지 위반으로 포착.
3. 결과: **RAG가 임상적·법적으로 올바르게 행동(119 안내 등)할수록 법률 점수가 깎이는 역설** → both-A 구조적으로 도달 불가.

## 5-b. 옵션 A 적용 결과 — 법률축 해결 (분리 법률기준 + gpt-5.4, 200샘플)

`rag_legal_eval`(RAG 트랙 전용 법률기준, 라이브 무영향) 적용 후 동일 200샘플 재측정(실행 `run-batch-eval-5wlhx`):

| 평가축 | gpt-5.4 원기준 | **gpt-5.4 분리기준** |
|---|---|---|
| 법률 A | 25% (50/200) | **99.5% (199/200)** |
| 문진 A | 26% (52) | 25% (50) |
| **both_A** | 7.0% | **25.0%** |

- 법률 분포: **A 199 / B 1** (F·C·D 0). `DIAG-100` 법률 B88→**A92**로 정정.
- **진단 확정**: 법률 병목은 전적으로 평가기 과교정이었고, 분리기준으로 해소.
- **병목 이동 → 문진축**: both_A=50은 사실상 문진 A=50과 일치(법률이 99.5%라). 문진 B 120건이 대부분 80~84점(A문턱 85 직전).

### 문진 B 적체 사유 (gpt-5.4, CONS_MISS 집계)
1. **structuredApproach(보통 11/15)**: RAG의 4단 구조가 설명(②③)을 질문(④)보다 먼저 제시 → "정보 제공보다 문진 우선이 아님"으로 감점. 설명+질문 병행을 정상 인정 안 함.
2. **redFlagScreening**: 폐색전증 위험인자(다리 붓기·장거리 이동)·실신 여부 등 추가 응급질문을 더 요구.
3. patientContext/symptomExploration의 세부 누락(복용약·반복패턴 등) 소폭 감점.

→ 법률축과 동일 패턴(gpt-5.4가 RAG 형식·표준 대응을 과감점)이 문진축에서 재현.

## 5-c. 옵션 A 2단계 — 문진축까지 분리 + red-flag 보강 (최종, 200샘플)

`rag_consultation_eval`(4단 구조 정상 인정) + RAG 프롬프트 ④ⓑ red-flag 질문 보강 적용(실행 `run-batch-eval-dnl8j`):

|---|---|---|---|
| gpt-5.4 원기준 | 25% | 26% | 7.0% |

- 법률 A 200/200, 문진 A 162.

### 잔여 미달 38건 (전부 문진축, 법률 100%)
- 카테고리: diagnosis 22, 피부 4, 비뇨생식기 4, 전신·피로·발열 3, 정신건강 3, 감각기관/머리뇌 각 1.
- 성격: **대부분 실제 문진 깊이 부족(정당한 감점)** — 예: 멍·출혈인데 코피/혈뇨/가족력 미질문, 인지저하인데 편측마비·실어증·얼굴처짐 미선별, 발진인데 피부분절·물집 진행 미확인. 평가기 과교정이 아니라 답변이 보강될 여지.
- 최저점(DIAG-083 문진 D49 등)은 구어체 단답 요구 질문에서 문진을 거의 안 한 경우.

### 결론
RAG 답변 품질은 우수했고, both_A의 진짜 병목은 **평가기 과교정(법률·문진 양축)** 이었음이 정량 확인됨. 라이브 평가 시스템을 건드리지 않는 RAG 트랙 전용 분리기준 + 답변 red-flag 보강으로 **gpt-5.4(엄격 모델)에서 both_A 81%** 달성. 남은 19%는 대체로 실제 문진 깊이 향상 과제.

## 5-d. 문진 깊이 보강 시도 — 플래토 확인 (실행 `run-batch-eval-wwmvd`)

미달 38건 전수분석(redFlagScreening 최약 18.5/25; 최빈누락 감염19·발열14·동반12·출혈8·가족력5)을 반영해 RAG 프롬프트 ④ⓐ(동반증상 구체화)·ⓑ(발열·감염·신경학적 전신징후)·ⓒ(가족력·항응고제)·ⓓ(경증/중증 차등)를 보강하고 동일 설정 재측정:

| | 최종(dnl8j) | 깊이보강(wwmvd) |
|---|---|---|
| 법률 A | 200 | 199 |
| 문진 A | 162 | 161 |
| both_A | 81.0% | **80.5%** |

- **순효과 ≈ 0 (노이즈 범위)**. 프롬프트 깊이 보강이 both_A를 못 올렸고, 답변이 길어지며 법률 1건이 B로.
- 해석: **프롬프트 레벨 튜닝은 수익체감 한계 도달**. ~80%가 현 RAG + gpt-5.4(엄격 평가기)의 안정적 천장.
- 잔여 미달은 (1) 일반 프롬프트로 끌어내기 어려운 증상별 임상 깊이, (2) gpt-5.4 평가 변동성(temp 0.1에도 ±1~2%)이 섞임.
- 깊이보강 변경(가족력·감염 선별 등)은 임상적으로 타당해 **유지**(점수 중립, 답변 품질엔 플러스).
- 추가 향상 레버는 프롬프트가 아니라: 증상별 문진 근거 KB 강화 / 다중 실행 평균(변동성 제거) / 카테고리 비례 측정.

### 종합 결론
